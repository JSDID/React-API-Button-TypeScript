# React API Button с TypeScript


## 🚀 Возможности

- **ApiButton** - кнопка для создания постов через API
- **PostsList** - компонент для отображения списка постов
- **Полная типизация** - все компоненты используют TypeScript интерфейсы
- **Обработка ошибок** - корректная обработка ошибок API
- **Современный UI** - красивые анимации и адаптивный дизайн

## 📁 Структура проекта

```
src/
├── components/
│   ├── ApiButton.tsx      # Компонент кнопки с API
│   ├── ApiButton.css      # Стили для кнопки
│   ├── PostsList.tsx      # Компонент списка постов
│   └── PostsList.css      # Стили для списка постов
├── services/
│   └── api.ts            # API сервис с axios
├── types/
│   └── index.ts          # TypeScript интерфейсы
└── App.tsx               # Главный компонент
```

## 🔧 Интерфейсы

### Post
```typescript
interface Post {
  id: number;
  title: string;
  body: string;
  userId: number;
}
```

### CreatePostRequest
```typescript
interface CreatePostRequest {
  title: string;
  body: string;
  userId: number;
}
```

### ApiButtonProps
```typescript
interface ApiButtonProps {
  onSuccess?: (data: CreatePostResponse) => void;
  onError?: (error: string) => void;
  disabled?: boolean;
  className?: string;
}
```

## 🎯 Компоненты

### ApiButton
Кнопка для создания постов через API с состояниями:
- **Обычное состояние** - "Создать пост"
- **Загрузка** - "Загрузка..." с анимацией
- **Успех** - "Успешно!" с зеленым цветом
- **Ошибка** - отображение ошибки с красным цветом

### PostsList
Компонент для отображения списка постов:
- Автоматическая загрузка при монтировании
- Кнопка обновления данных
- Обработка состояний загрузки и ошибок
- Адаптивная сетка карточек

## 🛠 Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите проект:
```bash
npm run dev
```

3. Откройте браузер по адресу: `http://localhost:5173`

## 📡 API

Проект использует [JSONPlaceholder](https://jsonplaceholder.typicode.com/) для демонстрации API:

- **GET /posts** - получение списка постов
- **POST /posts** - создание нового поста

## 🔄 Состояния компонентов

### ApiButton состояния:
- `loading` - запрос в процессе
- `success` - запрос выполнен успешно
- `error` - произошла ошибка

### PostsList состояния:
